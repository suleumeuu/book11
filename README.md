# C++ машинаға бағытталған бағдарламалау — электрондық оқулық

## GitHub Pages-ке орналастыру
1. Осы папканың ішіндегі БАРЛЫҚ файлдар мен папкаларды репозиторийдің негізгі деңгейіне (root) жүктеңіз.
2. `index.html`, `viewer.js`, `viewer.css`, `contents-data.js` файлдары бір деңгейде болуы керек.
3. `assets/book.pdf` файлы `assets` папкасының ішінде қалуы керек.
4. GitHub репозиторийінде Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save таңдаңыз.

## Мазмұннан бетке өту
Сол жақтағы мазмұн мәзірінде әр тақырыпқа тиісті PDF бет нөмірі берілген. Тақырыпты басқанда оқулық бірден сол бетке ауысады. Мәзірді жоғарғы сол жақтағы ☰ батырмасымен ашуға болады. Үлкен экранда мәзір автоматты түрде ашылады.

`source-files/` ішіндегі файлдар — бастапқы материалдардың көшірмелері. Сайттың жұмысы үшін негізгі `assets/book.pdf` файлы қолданылады.
